# Influence Rock website prototype

Responsive, single-page Next.js and TypeScript implementation of the selected light sage design.

## Run locally

```bash
npm install
npm run dev -- --port 4173
```

Open `http://localhost:4173`. Use `npm run build` for a production compile and `npm run typecheck` for TypeScript validation.

## Included interactions

- Animated global network paths and nodes, with reduced-motion support.
- Search by region, country, expertise, industry, and objective. The results use a small illustrative dataset in `lib/content.ts`.
- Selectable capability details and a three-scenario carousel.
- Validated consultation form that prepares a local preview of the overview. It does not transmit or store submissions.
- Responsive navigation and mobile layout.
